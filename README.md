# Lab 1 — Веб-технології

Статичний веб-проєкт: HTML5, CSS3, TypeScript, ESLint, Prettier.

## Локальний запуск

Відкрийте `index.html` у браузері або через Live Server у VS Code.

```bash
npm install
npm run build
```
